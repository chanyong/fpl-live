## 발행 팁
- 제목·메타 설명은 front matter 값을 그대로 쓰고, 대표 이미지는 `cover-*.png`(1200×630)를 OG 이미지로 지정한다.
- 이미지는 블로그 플랫폼에 직접 업로드한다(네이버 블로그·티스토리·Medium 등은 상대 경로를 못 읽는다). `diagram-*` 와 `rank`/`quadrant` 는 샘플 데이터 도식이라 본문에 "샘플/예시" 표기가 들어 있다.
- 링크의 `?ref=blog-ko-NN` / `?ref=blog-en-NN` 꼬리표로 글별 유입을 구분한다.
- 글 번호 간 내부 링크(`02-…md`)는 플랫폼에서 해당 글의 발행 주소로 바꿔 넣는다.
- 가격 변동 비율·전망 기준(±95%/±100%), 차별화 기준(소유율 10%·폼 6)은 FPL Live 기준값이며 FPL 공식 수치가 아니다.
